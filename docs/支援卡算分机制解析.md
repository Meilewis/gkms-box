## 一、整体工作表与计算流水线

整套表格由 4 层公式串联而成（另有 `更新日志`、`其他端直达二维码` 两张说明表）：

```text
  [词条] 数值表 + [持有情况] 你的各卡破数(-1~4) + [路线] 剧本参数与动作次数
                                  │
                                  ▼
      [第一属性比较] / [第二属性比较] / [第三属性比较]
        · 计算每张卡在对应槽位的「当前破数期望值」与「满破期望值」
        · 按 流派(感性/理性/非凡/通用) × 属性(红/蓝/黄) × 是否SP卡 分栏归类
                                  │
                                  ▼
                           [卡组计算]
        · 按各属性最低 SP 数要求，选出第一/二/三属性最强候选卡（自动去重）
                                  │
                                  ▼
                           [借卡计算]
        · 对 5 种属性配比方案分别枚举 12 种借卡替换（6个同卡满破 + 6个全卡池最强满破）
        · 取净增量最大者，回填到 [路线] 顶部输出「最终借卡」「最终卡组」与「总属性」
```

## 二、支援卡单卡属性计算机制（`词条` + `持有情况`）

### 1. 持有与突破数规则
在 `持有情况` 中，每张支援卡占用一块独立区域，记录其**破数**：
- `-1`：未持有（该卡当前期望属性计为 `0`，但**满破属性值**仍会在比较表的 `J` 列继续计算，供借卡推荐池使用）；
- `0 ~ 4`：0 破至满破（4 破）。
- 根据破数，从 `词条` 表读取 SSR / SR 各档位对应数值（部分词条区分 `0~2 破` 与 `3~4 破`，或 `0~3 破` 与 `4 破`，基础值与百分比则按 `0/1/2/3/4` 五档查表）。

### 2. 单卡收益的 3 大组成部分（为什么放不同属性槽位差很多）

单张卡放在**第一 / 第二 / 第三属性**时，分别按如下公式计算并向下取整（`INT`）：

$$\text{单卡期望属性} = \text{INT}\Big(\text{固定项} + \text{百分比项} + \text{触发词条项} (+ \text{道具/塞卡修正})\Big)$$

#### ① 固定项（与属性槽位、路线次数均无关）
- **初期属性（基础值）**：如 SSR 0~4 破为 `52 / 55 / 59 / 62 / 65`，SR 为 `37 / 40 / 43 / 46 / 49`；
- **事件属性（事件）**：支援卡固定事件给的属性白值（如 SSR 0 破 `30`、1~3 破 `35`、4 破 `40`；SR 为 `22 / 26 / 30`）。

#### ② 百分比项（强烈受“放第几属性”与“路线基础值”影响）
- **计算公式**：$(\text{百分比} / 100) \times \text{对应属性的基础属性值}$
  - 放第一属性：乘以 `路线!B11`（一属性值）
  - 放第二属性：乘以 `路线!B12`（二属性值）
  - 放第三属性：乘以 `路线!B13`（三属性值）
- **游戏含义**：百分比加成（如 SSR 满破 `8.5%`）吃的是你在培育过程中通过打分、基础练习等攒出来的属性基数。主属性基础值远高于二、三属性，因此**高百分比词条卡放主属性收益极高，放三属性收益大幅缩水**。

#### ③ 触发词条项（分为“绑定属性槽位”与“全路线通用”两类）
1. **绑定属性槽位的词条**（放哪一属就吃哪一属的次数）：
   - **训练（全训练）**：分别乘 `一属训练 (B14)` / `二属训练 (B17)` / `三属训练 (B20)`
   - **SP 训练（sp训练）**：分别乘 `一属sp (B15)` / `二属sp (B18)` / `三属sp (B21)`
   - **通常训练**：分别乘 `一属通常 (B16)` / `二属通常 (B19)` / `三属通常 (B22)`
   > 因此“SP 训练加成 / 普通训练加成”卡放进你基本不去踩的三属性位置时，这部分收益就是 `0`。
2. **全路线通用触发词条**（与放第几属性无关，只取决于当前剧本/路线里动作发生的次数）：
   - **抓卡类**：抓 A 卡(`B23`)、抓 M 卡(`B24`)、抓好调卡(`B25`)、抓温存卡(`B26`)、抓好印象卡(`B27`)、抓集中卡(`B42`)、抓元气卡(`B43`)、抓彩卡(`B44`)、抓干劲卡(`B45`)
   - **强化 / 删卡 / 变卡类**：A 强化(`B28`)、M 强化(`B29`)、删卡(`B35`)、删 M 卡(`B36`)、删 A 卡(`B37`)、变卡(`B38`)、买卡(`B50`)、道具获得(`B47`)
   - **行程 / 商店 / 试验类**：营业(`B30`)、外出(`B31`)、休息(`B32`)、相谈(`B33`)、支给(`B34`)、相谈饮料(`B39`)、饮料(`B40`)、指导(`B41`)、进特别指导(`B46`)、试验结束(`B48`)、20SP(`B49`)
   - **次限类词条（带触发次数上限）**：如限 2 次或限 3 次生效的词条（次限外出、次限删卡、限三指导、限 2 次支给/相谈、变基础卡等），公式使用 `IF(路线次数 > 上限, 上限, 路线次数)` 截断计算。

### 3. 比较表中的额外筛选与开关（`第一/二/三属性比较`）
在比较表中，除了基础分值，每张卡还带以下属性与开关：
- **流派（`E` 列）**：`1` = 感性、`2` = 理性、`3` = 非凡、`0` = 通用（通用卡可进任意流派卡组，非当前流派的卡不进分栏）；
- **SP 标记（`F` 列）**：是否为 SP 训练出现率提升卡（`1` = 是，`0` = 否）；
- **属性颜色（`G` 列）**：`1` = 红（Vo）、`2` = 蓝（Da）、`3` = 黄（Vi）；
- **污染标记（`H` 列）**：`0/1`（表示该卡带出卡或事件是否会污染牌库）；
- **带出道具或 S 卡（`I` 列）**：标明卡面附带的挑战道具/技能卡备注（如水枪、相册等）；
- **道具属性开关（`路线!B4`）**：设为 `"计算"` 时，带道具收益的支援卡读取含道具加成的列，否则只读基础期望值；
- **塞卡等效属性开关（`路线!C6`）**：设为 `"计算"` 时，向卡组塞卡的词条固定额外 `+20` 等效属性（对应表头“塞卡等效属性(20/1)”）；
- **同分去重微调**：比较表在排序值末尾统一减去 `ROW() * 0.00001`，避免不同卡片算分恰好相等时 `MATCH/LARGE` 定位冲突，最终展示时再用 `ROUNDUP(..., 0)` 还原为整数。

## 三、路线（剧本）如何影响算分与配卡（`路线` 表）

不同剧本和流派路线的差异，在计算模型中被抽象为两类参数：**各属性的基础属性值（影响百分比收益）** 和 **各项培育动作的发生次数（影响词条收益）**。

### 1. 顶部全局配置（`路线!B1:C6`）
- **第一属性（`B1`） / 第二属性（`B2`）**：红 / 蓝 / 黄（由此可推知剩余一色为第三属性）；
- **流派（`B3`）**：感性 / 理性 / 非凡；
- **最低 SP 数（`C2 / C3 / C4`）**：分别为红、蓝、黄设定至少带几张 SP 率卡；
- **道具属性（`B4`）**：计算 / 不计算；
- **审查类型（`B5`）**：单极 / 均衡（影响 NIA master 的基础值与训练次数分配）；
- **塞卡等效属性（`C6`）**：计算（+20） / 不计算。

## 四、自动配卡与借卡推荐逻辑（`卡组计算` + `借卡计算`）

### 1. 支持的 5 种属性槽位配比
表格顶部与 `借卡计算` 共输出 5 组不同色彩结构的 6 卡方案：
1. **`3 / 3`**：3 张第一属性 + 3 张第二属性（`借卡计算` E 区）
2. **`3 / 2 / 1`**：3 张第一属性 + 2 张第二属性 + 1 张第三属性（`借卡计算` K 区）
3. **`3 / 2 / 1` 反序（即 `2 / 3 / 1`）**：2 张第一属性 + 3 张第二属性 + 1 张第三属性（`借卡计算` Q 区）
4. **`2 / 2 / 2`**：2 张第一属性 + 2 张第二属性 + 2 张第三属性（`借卡计算` W 区）
5. **`2 / 4`**：2 张第一属性 + 4 张第二属性（`借卡计算` AC 区）

### 2. 选卡与去重规则（`卡组计算`）
- 按当前流派过滤，按**最低 SP 数**要求优先保证对应属性槽位选足 SP 率卡（剩余槽位在含非 SP 卡的全部候选池中取高分）；
- 顺序挑选时带跨槽位去重（因为通用流派卡或同色高分卡不会在同一个 6 卡编队里重复上阵两次），按「第一属性 → 第二属性 → 第三属性」顺延递补次高分卡。
  > **工程实现备注**：Excel 受限于单元格公式无法做组合穷举，只能用固定顺位贪心递补；如果用代码（JS/TS）实现，**既可以 1:1 复刻原表顺位算法对齐结果，也可以轻松改成全排列/精确搜索最优解**（避免跨槽位贪心引起的极少数次优解问题）。

### 3. 借卡计算逻辑（`借卡计算`）
对上面挑出的初始 6 张自持卡组，枚举 **12 种借卡替换方案**：
- **方案 1~6（同卡替换，`R10~R15`）**：将 6 个位置中某一位置上你自己的卡片，替换为好友的**同名满破卡**（收益差值 = 满破属性 `J` 列 − 你当前破数属性 `D` 列）；
- **方案 7~12（最高值卡 / 异卡替换，`R16~R21`）**：将 6 个位置中某一位置替换为全卡池（不限是否持有）中**满破期望最高且满足该槽位属性/流派/SP 要求、且不与其余 5 张重复**的最强满破卡（收益差值 = 借入满破卡属性 − 被换出卡当前属性）；
- 对比 12 个差值取 `MAX`，输出：
  - **最终借卡**：收益增量最大的那张【借】卡；
  - **最终卡组 & 总属性**：替换完成后的 6 张卡名称与 6 张卡属性之和。

## 七、HIF 专项实测口径（已确认）

针对后续开发与本地原型验证，已先聚焦 **HIF** 并确认如下实测口径（对应本地原型目录 [hif-planner](file:///e:/软件/GEMINI工作区/gkms-box/hif-planner)）：

1. **属性上限与寻优目标**：HIF 单属性面板上限为 **`3200`**，超过 `3200` 的溢出部分严格计为 **0 收益**；寻优以截断 `3200` 后的**有效三维总和最大化**为第一目标（避免把借卡名额或高分槽位浪费在溢出的属性上）。
2. **考试打分拆分**：
   - **选拔**：默认 `100%` 全控第一属性（可微调）；
   - **本战 1** 与 **本战 2**：提供两个独立可填的三属性打分比例输入框/参数。
3. **抓 SSR 卡次数**：默认按 **`10`** 张计算，支持用户自定义修改（对应 `路线!B44`）。
4. **S 卡道具与塞卡**：
   - **S 卡自带道具数值默认全发**（即默认等价于原表 `路线!B4="计算"`）；
   - **局内喝饮料不计**（只算局外行动与词条获取/相谈买饮料）。
5. **动态联动机制**：
